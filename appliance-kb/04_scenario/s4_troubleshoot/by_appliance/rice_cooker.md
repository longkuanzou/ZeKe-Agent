# s4 故障排查 · 电饭煲差异

> 通用五步法见 `../playbook.md`。本文只写电饭煲特有部分。
>
> 电饭煲最关键的一条：**绝大多数投诉是"做出来的饭不对"，不是"机器坏了"**。
> 说明书把"饭不好吃"的成因全归到米水比、功能选择、异物、蒸汽阀、内锅变形五条，
> 没有一条指向电路。所以电饭煲的排查重心在**使用**，不在硬件。

## 三层排查（按顺序，不要跳）

```
① 米与水   米种对不对？按水位线加的吗？功能键选对了吗？
② 内锅与盖 内锅放平了吗？锅底/加热盘有异物水渍吗？蒸汽阀装到位了吗？内盖密封圈错位吗？
③ 电路     灯亮不加热？报传感器类代码？只有上层夹生（远红外机型）？
以上都不成立 → 送修
```

## 各省略一步的典型后果

| 跳过的步骤 | 直接送修会怎样 |
|---|---|
| 米水比例 | 师傅上门一看没问题，机器退回来还是夹生，二次投诉 |
| 内锅是否放平 | 检锅保护不加热被当成"不通电"，多跑一趟 |
| 蒸汽阀是否装到位 | 漏汽导致上层夹生，换主板也没用 |
| 海拔 | 高原（>2000m）用户永远煮不熟，属超范围使用不是故障 |

## 三个机型族的关键差异（决定话术走向）

| 族 | 代表型号 | 加热方式 | 答复要点 |
|---|---|---|---|
| 底盘加热 + 涂层胆 | 美的 AFB4041RL / 苏泊尔 SF40FC871、SF50FC733 | 电热盘 | 涂层胆禁用钢丝球、禁入洗碗机 |
| 底盘加热 + 不锈钢零涂层 | 美的 MB-RE576S（316L） | 电热盘 | **可以用钢丝球**，不要统一说"不能" |
| 底盘加热 + 顶部远红外 | 苏泊尔 F40H8093S / F40H9083S / F50X96 | 电热盘 + 远红外管 | 远红外管坏了表现为"能煮熟但上面夹生、饭不香"，最易误判 |
| IH 电磁加热 | 美的 MB-40HB9T | 线圈盘 | 功率 1300W 级，故障章写"线圈盘"不是"电热盘" |

**同一品牌内部，内胆能不能用钢丝球这件事是分机型的**——必须先确认型号，再回答。
这一条之前被判成"OCR 误识"，后来靠型号资料确认是真实差异（316L 零涂层确实耐刮）。

## 电饭煲的代码

苏泊尔是唯一有说明书原文代码表的（E0 顶部传感器 / E1 底部传感器 / E5 检不到锅 /
E6 无蒸汽水杯 / E7 防溢探头），可以按条答。

美的电饭煲的逐码表来自官方说明书网络件（E0 过零 / E1 底部传感器 / C4 无锅保护 / C2 IGBT 过热……），
可对外给含义，但遇到质疑以随附说明书为准。

处置上只有两条要记：
- **E5 / E6 / C4 是放置类**（内锅、蒸汽水杯、无锅），先引导，不建单
- **传感器 / 通信 / 模块类**直接送修，不引导反复通电

## 电饭煲的停机红线

- 漏电麻手、焦味冒烟 → 立即断电
- 内胆涂层脱落 → 停止使用（脱落处局部过热，且涂层碎屑混入食物）
- 微压/压力机型锅内仍有压力时开盖 → 禁止，必须等自然泄压（烫伤风险）

## 售后模式：送修优先，不是上门

电饭煲属小家电。苏宁/美的/苏泊尔的主流模式是**送到特约服务商**或寄修，
上门属于部分区域的增值服务。所以：

- 不要说"师傅马上上门"
- 先问用户所在城市是否在服务商覆盖范围
- 内胆、密封圈、蒸汽阀这类配件问题优先"寄件自换"，不必整机送修

## 不该做的事

- 不引导用户拆上盖查传感器、不短接热熔断器（一次性保护，短接会烧机甚至起火）
- 不对"饭不好吃"直接判定机器故障
- 不回答具体降糖百分比（说明书没有检测报告）
- 不把 IH 与底盘加热的话术混用（"线圈盘坏了"对底盘机型是错的）
