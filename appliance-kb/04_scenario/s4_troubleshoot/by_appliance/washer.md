# s4 故障排查 · 洗衣机差异

> 通用五步法见 `../playbook.md`。本文只写洗衣机特有部分。
> 洗衣机的故障排查**和空调完全不同**：不看滤网和室外温度，看电/水/排水/门。

## 四查（顺序不可调）

```
① 电  插座有电？跳闸？童锁开了？
② 水  水龙头开了？水压 ≥0.1MPa、流量 ≥8L/min？进水管弯折？进水阀过滤网堵？
③ 排水 排水管末端 0~100cm？弯折？插太深？浸在水里？泵滤网异物？
④ 门  关好听到锁合声？运行中门锁不放行？
```

四查之后才是"机器本身"。这个顺序的价值在于：**洗衣机报上来的"故障"里，一半以上能在这四查里结束**。

## 首装就报振动：先问运输螺栓

背面 4 颗运输固定螺栓（13 号扳手松开，拆下后装入孔塞）没拆就脱水，机器会剧烈震动甚至移位。
这是洗衣机安装最高频的上门返工原因，也是"新机器就是坏的"这类投诉最常见的真相。

**处置**：属安装遗漏，可以申请返修；不要按"机器质量问题"直接走换机。

## 上排水的三个坑

本批西门子机型与小天鹅 TG 系列都是**上排水**，它们的排水故障不从地漏查：

| 坑 | 表现 | 正确处置 |
|---|---|---|
| 排水管末端高于 100cm | 排水泵顶不上去，报排水超时 | 降到 0~100cm 区间 |
| 末端浸在排出的水里 | 回流，内筒反复有水 | 抬高末端并固定 |
| 插进下水道过深 | 形成反压，排水慢 | 留出空气间隙 |

用户说"我家有地漏啊"，也不能因此判断"应该下排水"——机型是上排水就是上排水，说明书 p17 有依据。

## 两套代码体系（小天鹅）

小天鹅同时存在数字码与 E 码，用户报的"E1"和面板上的"630"不是一回事：

- 滚筒 TG 系列：3 位数字码（630 门未合上、613 料盒未关）
- 波轮 TB 系列：E 开头代码（E1 进水超时、E21 排水超时）
- 通用保护提示：Ub / UF / U3（衣物不平衡）

**先问"几位、纯数字还是带字母"**，再查 `05_brand_ref/littleswan/fault_codes.yaml`。

西门子则是 E/F 双前缀：E16 与 F16 含义相同（新机型显示 E，老机型显示 F），不是两种故障。

## 洗衣机特有的"正常现象"（别当成故障）

| 现象 | 真相 |
|---|---|
| 面板显示 Ub / 脱水延时 | 偏心保护，低速检测后重新分布衣物 |
| 衣物少时脱不干 | 同上，加几件均匀分布即可 |
| 程序时间突然变长 | 检测到泡沫，静置或追加漂洗 |
| 运行中门打不开 | 门锁安全保护（西门子结束后约 2 分钟自动解锁） |
| 排水泵"嘎嘎"声 | 排水泵工作声 |
| 断电后来电没继续 | 断电记忆生效与否取决于断电期间是否按过电源键 |

## 洗衣机的停机红线

- 底座积水 / AquaStop 报警（西门子 E23）→ 先关水龙头再断电，**不要复位后继续用**
- 机身漏水伴随漏电麻手 → 立即断电
- 焦味、冒烟 → 立即断电
- 门锁反复动作、听到异响 → 停机，禁止撬门

## 不该做的事

- 不引导用户拆机、拆门锁、撬门
- 不在确认"运输螺栓是否拆除"之前判断机器质量
- 不按空调经验问"滤网脏不脏"（洗衣机没有滤网要洗，只有排水泵滤网）
- 不对 Ub 类保护提示建单
- 不承诺"能叠放"——要按两个机型组合确认，见 `03_product/washer/*/install.yaml#space`
