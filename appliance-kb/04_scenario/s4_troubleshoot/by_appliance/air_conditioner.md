# s4 故障排查 · 空调差异

> 通用五步法见 `../playbook.md`。本文只写空调特有、不能套到洗衣机/电饭煲上的部分。

## 排查入口就是那四步

```
① 模式对吗（送风/除湿不制冷）
② 设定温度对吗（制冷要低于室温，制热要高于室温）
③ 滤网脏不脏 / 门窗开没开 / 有没有热源
④ 是否超出工作温度范围（室外 43℃ 以上效果会下降）
以上都排除 → 按机型给自查步骤 → 报修
```

## 型号差异清单（回答前必看）

| 项 | 海尔 E1-1 | 美的 Q2 |
|---|---|---|
| 代码表 | 说明书无（品牌级表见 05_brand_ref/haier，网络来源，仅内部分诊） | 说明书有代码类别，无逐码释义（逐码表见 05_brand_ref/midea） |
| 制冷保护温度 | 室外 >62℃ | 室外 >65℃ |
| 制热保护温度 | 室外 -35~24℃ | 室外 -35~24℃ |
| 自清洁 | 有 | 无（问"自清洁坏了"要纠正前提） |
| 最大管长 | 10m | 15m（可加长） |

上面这张表只是"哪些项会不一样"的清单，不是答案本身。

## 空调特有的"正常现象"（别当成故障）

| 现象 | 真相 | 出处 |
|---|---|---|
| 流水声 / 咕嘟声 | 制冷剂流动 | 海尔 p29 |
| 噼啪声 | 塑料热胀冷缩 | 海尔 p29 |
| 室内机冒水雾 | 冷凝水雾 | 海尔 p29 |
| 制冷时自动转送风 | 防结霜保护 | 海尔 p29 |
| 关机后不能立即开 | 压缩机 3 分钟保护 | 海尔 p29 |
| 制热时外机冒蒸汽 | 化霜 | 海尔 p30 |
| 制热关机后内机还转 | 去余热 | 海尔 p30 |
| 出风口滴水（高湿） | 凝露 | 美的 p31 |
| 显示温度与实测不同 | 自动温度补偿 | 美的 p31 |

## 空调的停机红线

- 室内机漏水（不是出风口凝露）→ 立即停机
- 空开/漏保频繁跳闸 → 立即停机
- 焦味、冒烟 → 立即停机
- 报压缩机/IPM/高压保护类代码 → 停机，不要反复重启

## 空调的代码体系

海尔与美的都**没有逐码释义**的说明书，品牌级代码表是网络来源（`verified: false`），
只能做内部分诊：

- 美的有一份说明书原文给的处置流程——**关机 → 断电 10 分钟 → 上电开机 → 仍显示则报修**，可以直接给用户
- 海尔没有官方流程，可以给同款通用流程，但要说"这是通用做法，不是说明书要求"

对外只说类别（"传感器或通信这类问题"），不说"E1 就是室内环温传感器坏了"。

## 空调话术的特殊注意

- 用户说"不制冷"，先问"吹出来的风跟室温一样吗"——这一句比问十个参数有用
- 用户说"外机不转"，先问"是不是刚关机又开"（3 分钟保护）
- 用户说"电费高"，不要引到故障，直接转 s1 的耗电口径
- 用户说"要加冷媒"，先按 `weak_effect` 排查缺冷媒的证据（管路结霜），没有证据不加
