# s2 安装咨询 · 空调差异

> 通用规则见 `../playbook.md`。空调是三个品类里安装条件最复杂的一类，**三查缺一不可**。

## 三查

```
① 电  专用回路？插座带地线？线径够不够？
② 位  墙面承重？外机位置可用？与可燃面/消防通道的距离？
③ 管  走管长度？内外机高度差？要不要加长、要不要补冷媒？
```

三查全过才能说"可以装"。任一项不过，给具体原因和替代方案。

## 两个品牌的硬指标差异（必须按型号查，不能记平均值）

| 项目 | 海尔 KFR-35GW/E1-1 | 美的 KFR-35GW/Q2 |
|---|---|---|
| 最小房间面积 | >4㎡ | ≥4㎡ |
| 最大管长 | 10m | 15m（可加长） |
| 内外机高度差 | ≤5m | 未标注 |
| 加长补冷媒 | 超 5m 后每米 20g | 每米 18g |
| 电源要求 | 线径容量 > 最大电流 1.5 倍；独立专用插座带地线 | 最大电流<16A 配插头，须专用分支回路 |
| 其他硬指标 | 距可燃面≥1.5m；临街外机≥2.5m；断电后隔 3 分钟再上电 | 安装架承重≥4 倍机重且≥200kg；2m 以上作业须系安全带 |

> 这两个型号的加长规则、管长上限都不一样。**用"一般空调都 15 米"回答，一半的用户会被误导。**

## 空调的收费项（金额见 05_brand_ref/{brand}/fee_schedule.yaml）

- 高空作业费（按楼层/外挂方式，4 楼及以上 + 墙外施工）
- 加长连接管（按米，注意各品牌补冷媒规则不同）
- 支架 / 打孔 / 拆装防盗网
- 上楼费（无电梯、高楼层、大件柜机）
- 远程上门费（超出服务半径）

空调**没有**加装水龙头、地漏改造这类水路项目——那是洗衣机的。

## 上门前给用户的确认清单

```
装前麻烦确认几件事：
1. 安装位置有专用插座吗（空调要单独一路）
2. 室外机放哪，有预留机位还是要挂墙
3. 墙面是砖墙还是混凝土
4. 楼层和有没有电梯
5. 大概要走几米管
6. 房间面积多大（R32 机型要≥4㎡）
```

## 空调特有的坑

1. 把"最大加长长度"当"标配长度"——标配通常 3~5 米，超出部分才收费
2. 把"待机功率"当"运行功率"——选线看最大输入电流
3. 忽略最小房间面积——R32 机型 4㎡ 是安全下限，不达标必须拒绝
4. 移机、拆装旧机当成安装——都属于收费项目，要单独确认
5. 柜机与挂机的上楼费、支架费、高空费都不同档，别按挂机口径报柜机
