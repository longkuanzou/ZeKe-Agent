# s2 安装咨询 · 电饭煲差异

> 通用规则见 `../playbook.md`。
>
> **本文件存在的最大价值是"否认"**：电饭煲不需要安装。用户问安装问题时，
> 一半以上是把它当成空调/洗衣机来问，或者被别的商家的话术带偏了。

## 一句话结论

> 电饭煲免安装，拆箱插电就能用。不派安装工单，也不产生安装费。

这句话要放在回答的第一句，然后再讲要注意什么。顺序反了，用户会以为后面还有收费项。

## 真正需要确认的三件事

### ① 电

| 项 | 要求 | 为什么 |
|---|---|---|
| 插座 | 10A 三孔接地插座 | 与其它大功率电器共用插座会过热打火 |
| 延长线 | 不建议用排插 | 必须用时，所接电器总额定电流不得超过插座/线路额定值 |
| 接地 | 必须接地 | 不可用两孔插头或剪断地线 |

功率差异要知道：底盘加热 4L/5L 机型普遍 750~760W，IH 机型 1300W 级，
微压 + 顶部远红外的苏泊尔 4L 机型 1600W。**1600W 用老房子的 10A 线路要留意**，
但仍在 10A（2200W）承载范围内。

### ② 放置

- 平稳、干燥、耐热的台面；不要放炉灶旁、水槽溅水区、微波炉等发热电器上方
- **出汽方向不能有插座、吊柜、窗帘**——上盖蒸汽阀会向上/向前喷高温蒸汽，这是烫伤与吊柜受潮的主要来源
- 机身四周留散热空间；嵌入橱柜格时上方要留出开盖与出汽空间

尺寸口径（用户量柜格时最常问）：

| 型号 | 外形尺寸（宽×深×高） | 数据性质 |
|---|---|---|
| MB-40HB9T | 338×270×235mm | 官方产品页 |
| MB-AFB4041RL | 323×262×222mm | 官方产品页 |
| MB-RE576S | 323×262×252mm | 官方产品页 |
| SF40FC871 | 318×263×224mm | 官方产品页 |
| SF50FC733 | 384×285×257mm | 官方产品页 |
| F40H8093S / F40H9083S | 326×270×235mm | 官方产品页 |
| F50X96 | 未查到 | — |

这些是 `confidence: web` 值（非说明书原文）。报尺寸时必须加一句"以包装标贴为准"，
并提醒**留 2~3cm 余量**——量得刚好塞进去的用户，回去一定装不下（出汽口被顶住、盖子打不开）。

### ③ 开箱验收

```
1. 核对型号与面板丝印是否一致（同一份说明书常覆盖多个型号，同外观多型号很常见）
2. 检查内锅有没有磕碰变形（变形会直接导致受热不均、煮不熟，属到货即损）
3. 核对配件是否齐全（按型号查 product.yaml 的附件清单）
4. 首次使用：取出内锅与所有包装件，洗净擦干内外表面，可先煮一锅水倒掉去味
```

第 2 条是最有商业价值的一条：内锅变形在 7 天无理由期内属于可退换的"商品不完好之外"的
到货问题，但过了这个窗口就只能走维修，判定归属会变复杂。

## 电饭煲不存在的费用项（用户问到就直接否认）

- 安装费、装机费、调试费
- 高空作业费、上楼费（小家电，无此概念）
- 加长冷媒管、加长进水管、水龙头加装、地漏改造
- 支架费、拆门扩门洞

存在的只有：保外维修人工费、上门检测费、寄修运费、配件费（内胆/密封圈/蒸汽阀）。

## 高原

说明书给的正常工作海拔是 0~2000 米（SF50FC733 原文）。超过 2000 米的用户报"煮不熟/溢锅"，
先问海拔——属超范围使用，不能承诺"调一下就好"。这一条要在售前就问清，
装完再说就是纠纷。

## 不该做的事

- 不说"我们安排师傅上门安装"
- 不对"放不放得进橱柜"给肯定承诺（尺寸是网络值，且用户量的方式经常不对）
- 不承诺"任何台面都能放"（高温台面、软木台面、倾斜台面都有问题）
- 不把空调/洗衣机的上门前确认清单照搬给电饭煲用户
