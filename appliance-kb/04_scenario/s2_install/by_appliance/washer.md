# s2 安装咨询 · 洗衣机差异剧本

> 通用剧本见 `../playbook.md`，那一份是按空调写的（电/位/管三查）。
> 洗衣机没有外机、不走冷媒，换成**电/水/排水/门**四查。四条里有任意一条不过，就是"装不了"。

## 洗衣机四查：电、水、排水、门

```
① 电  插座位置、是否带地线、是否漏电保护、线能不能承受加热洗的大电流
② 水  有没有水龙头、接口是不是 3/4"，水压够不够（常见要求 0.03~1 MPa）
③ 排水  上排水还是下排水？有没有地漏？排水管最高点能不能低于限值？
④ 门  机器尺寸 vs 入户门宽/楼道拐角/卫生间门宽——这是退货率最高的原因
```

**四查的顺序不能换**。先问门，是因为前面三条都可以改造（加水龙头、加地漏、换插座），
只有门宽改不了；一旦门进不去，前面问的全是白问。

## 第④查：门宽怎么算

不是量门洞，是量**最窄通道**：

1. 楼道最窄处（很多老楼楼梯转角只有 60cm）
2. 入户门净宽（去掉门扇厚度、门把手）
3. 目标房间门净宽
4. 转弯处剩余空间（机器要立着抬过去，深度方向要留转身余量）

对比对象是**机器的最小通过尺寸**：滚筒机拆掉包装后按"宽×深"的较小边算，
波轮机可以侧翻抬，按高度以外的边算。具体数值只认 `03_product/**/specs.yaml` 里的 `size_mm`，
不得凭"10 公斤的机器大概 60 宽"这种经验值回答。

> 说明书里常写"门宽小于 X 请拆门"或"正面需预留 900mm 使用空间"——
> 后者是**使用**空间（开门、放衣服），不是**搬运**空间，两者不能混。

## 第③查：上排水 / 下排水（最容易答错的一条）

这两者的适用场景完全相反，答反了用户装完就返水：

| | 下排水 | 上排水 |
|---|---|---|
| 排法 | 靠重力，排水管必须向下走 | 靠泵，排水管要先抬高再排 |
| 必须要地漏 | 是 | 否（可排入水槽、洗衣机专用排水接口） |
| 典型场景 | 卫生间/阳台有地漏 | 厨房、无地漏阳台、想把水排进水槽 |
| 排水管高度 | 越低越好，不得高于机器底部太多 | 有**最大排水高度**限制，超了排不出去 |

西门子说明书原文（`WG52A108AW` 第 8 页）："为了不超过电器的最大排水高度，
排水软管的任何部位均不得高于电器安装面 100 cm 以上"，
并给出三种接法——虹吸管、盥洗盆、带橡胶套管的塑料管或下水道井口，均需用软管夹/弯管锁固。

**回答模板**：
> 这台是上排水，不用地漏，排水管挂到水槽边或者插洗衣机专用排水口就行。
> 但管子最高点不能超过机器底部 1 米，超了水排不出去。

排水方式取值只有"上排水/下排水"两种，存在同一型号不同批次不同的情况，
一律以 `specs.yaml` 的 `drain_type` 为准，**不得按品牌默认值回答**。

## 第②查：水

- 接口规格：多数为水龙头 3/4"（26.4 mm），说明书要求**用手拧紧**，不用扳手（会拧裂塑料螺纹）
- 水压：常见要求 0.03~1 MPa（小天鹅 TG10K60 说明书标注 0.03-1MPa），低于下限表现为"一直进水不进满"或直接报错
- 进水前必须先开龙头检查接口是否渗漏，这一步要写进上门清单

## 第①查：电

- 必须带地线，且建议独立回路 + 漏电保护（西门子说明书明确要求"应包含漏电保护断路器"）
- 带加热洗/烘干的机型功率明显高于纯洗涤，选线看 `specs.yaml` 的 `power_w`，不看"普通洗衣机 10A 就够"
- 插座不要放在机器正后方被机身挡住，否则插不上；也不要放在淋浴区

## 调平：不是"顺便"，是安装的必做项

说明书要求：松开防松螺母（17 mm 扳手）→ 转支脚 → **用水平仪检查** → 所有支脚牢靠落地 → 拧紧防松螺母。

调平没做好会直接表现为：
- 脱水时剧烈抖动、机器"走路"（用户描述为"跳舞/乱跑/咣当响"）
- 脱水噪音偏大（噪声限值是在标准安装条件下测的，不平就超标）

这条要写进安装完成后的验收话术，不是可选项。

## 运输螺栓：装完必须拆，不拆等于没装

滚筒机背面有 4 个运输防松螺栓 + 4 个套管（西门子：13 mm 扳手松开拆下，再装孔塞）。
**没拆就脱水**会剧烈震动甚至损坏机器，这是"新机第一次用就抖得厉害"的第一嫌疑。

回答"甩干抖得厉害"时，第一句先问："背面的运输螺栓拆了吗？"——比让用户报修快得多。

## 上门前给用户的确认清单（洗衣机版）

```
装前麻烦确认几件事：
1. 放机器的位置有水龙头吗？接口是不是普通的 3/4 螺纹
2. 有没有地漏？（决定能不能选下排水机型）
3. 插座在哪，带不带地线，会不会被机器挡住
4. 从楼下到房间，最窄的门口大概多宽
5. 要不要叠放烘干机 / 做嵌入柜（决定预留间隙）
```

## 收费项（洗衣机与空调不同，别套空调的收费表）

- 拆装运输螺栓、调平：属于基础安装，不应单独收费
- 加长进水管/排水管、加装水龙头、改地漏、拆门/扩门洞：属改造项，由用户或第三方做，需提前说明
- 高层无电梯上楼费、远程上门费：与空调同规则，见 `05_brand_ref/{brand}/fee_schedule.yaml`
- **洗衣机没有高空作业费和加长冷媒费**，出现这两项即为答错

## 最容易出错的五个点

1. 把"使用预留空间（正面 900mm）"当成"搬运通过尺寸"
2. 上/下排水说反——上排水的机器告诉用户"必须留地漏"，用户白改一次地面
3. 用"10 公斤机器都 60 宽"回答门宽——不同品牌差 5cm 就进不去
4. 忘了运输螺栓，让用户直接报修，师傅上门只拆了 4 个螺栓
5. 把烘干机的安装条件（需要排水/冷凝水盒）套到单洗机型上
