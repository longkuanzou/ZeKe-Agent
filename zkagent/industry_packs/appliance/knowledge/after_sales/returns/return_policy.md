# 退货与退款政策

## 七天无理由退货

自签收之日起 **7 天内**（含第 7 天），商品**不影响二次销售**的前提下可申请无理由退货：

- 商品本体、配件、包装、赠品齐全；
- 无使用痕迹、无磕碰划痕、无进液；
- 随机文件（说明书、保修卡）完整。

大型家电已安装的，需先拆机恢复包装状态，拆机费用按安装服务标准收取。

## 不支持无理由退货的商品

1. 已拆封的耗材类（滤芯、尘袋、清洁液）；
2. 定制尺寸或已改装的商品；
3. 因用户原因导致外观损坏的商品。

## 拆封了还能退吗

- **大家电（空调、冰箱、洗衣机）拆封后仍可申请**无理由退货，前提是**未安装、未使用**、
  本体与包装配件完整、不影响二次销售；已安装的需先拆机恢复包装，拆机费用按安装服务标准收取。
- **耗材类拆封后不支持**无理由退货：滤芯、尘袋、清洁液。
- 「拆封」是打开外包装；「安装/使用」才影响二次销售。仅开箱查看外观、未通电未进水的，可正常申请。

## 退款金额与时限

- 退款金额以**实际支付金额**为准，不含已使用的优惠券与运费；
- 审核通过后按原支付渠道退回，通常 1–5 个工作日到账；
- 商品需先寄回或由上门取件回收，**质检通过后**才发起退款。

## 退货与取消订单的区别

| 场景 | 正确操作 |
| --- | --- |
| 订单**未发货** | 只能**取消订单**，不能创建退货单 |
| 订单已发货但未签收 | 可拒收，或签收后走退货 |
| 订单已签收 | 走退货退款流程 |

## 需要人工审核的情形

以下情况系统不会自动受理，需转人工审核：

- 单笔退款金额较大（超过自助处理额度）；
- 签收已超过 7 天但仍申请退货；
- 同一用户短期内多次退货，需人工核实原因。
