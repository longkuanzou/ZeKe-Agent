# 安装条件与预留尺寸

> 本文列的是**硬条件**（不具备就装不上或不安全）。具体机型的尺寸以商品信息为准，
> 最终以师傅上门勘测结论为准；本文不替代现场判断。

## 空调

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 电源 | 插座规格与机型匹配，**建议独立回路**并可靠接地 | 柜机多为大功率，需专用回路 |
| 外机位 | 具备承重、通风、排水与检修空间 | 封闭阳台、内嵌机位需确认散热 |
| 排水 | 冷凝水可排至室外或地漏，管路有坡度 | 排水管坡度不足会倒流滴水 |
| 打孔 | 墙体允许开孔，避开承重钢筋与暗管 | 玻璃开孔需另议 |
| 高空作业 | 外机位无平台、无护栏时属高空作业 | 见《安装收费标准》 |

## 洗衣机

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 进水 | 有可用水龙头，配匹配的进水管 | 水压过低会影响进水速度 |
| 排水 | 地漏或排水口低于机身，排水管不打死弯 | 排水管过高会导致不排水 |
| 电源 | 三孔接地插座，避免与热水器等大功率共用 | 潮湿环境建议带防水盒 |
| 地面 | 平整、承重足够，机身可调平 | 地面空鼓会导致脱水震动大 |
| 门宽 | 入户门与安装位通道净宽建议不小于 60 cm | 滚筒机型需整体搬运 |

## 冰箱

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 散热间距 | 两侧与背部各留 5 cm 以上，顶部留 10 cm 以上 | 间距不足会导致不制冷、耗电上升 |
| 门与楼道 | 门宽与楼道转角可通过机身（含包装） | **大容量冰箱最常见的装不上原因** |
| 开门空间 | 门体全开需预留 90° 以上空间 | 抽屉式冷冻需更宽 |
| 电源 | 独立三孔插座，避免与微波炉等共用 | — |
| 静置 | 搬运后静置再通电（见《首次使用怎么做》） | 倾斜搬运后需更长时间 |

## 自检口诀

买之前量三样：**门能不能进、电够不够用、水排不排得出去**。
任一项不确定，先让客服按型号核对尺寸，不要等到师傅上门才发现。
