# 安装服务

## 免费安装范围

| 品类 | 免费安装内容 |
| --- | --- |
| 空调 | 标准挂机/柜机安装（含 3 米管线、1 个支架） |
| 洗衣机 | 进排水管连接、调平 |
| 冰箱 | 就位、调平、通电试机 |

超出标准范围的项目（加长管线、高空作业、打孔、旧机拆除、外机吊装）**另行收费**，
项目与标准见《安装收费标准》，任何收费必须在施工前确认、不得先装后报价。

## 预约与上门

1. 提交安装工单时选择期望时间段（建议提供两个备选时间）；
2. 安装师傅会在上门前 30 分钟电话联系；
3. 用户改约请提前 2 小时告知，避免师傅空跑；
4. 如遇天气原因（高空作业）无法施工，会重新预约，不额外收费。

## 安装前需要准备

- **水电与空间条件**：电源、进水、排水、预留尺寸、门宽等硬条件见《安装条件与预留尺寸》，
  建议下单前先自检，避免师傅上门后无法施工；
- 清理安装位置周边障碍物，腾出施工空间；
- 物业报备（部分小区需提前登记，空调外机位尤其常见）；
- 保留好包装材料至试机确认完成，便于异常时退换。

## 安装质量问题

安装完成后请当场试机确认。若 7 天内发现安装导致的漏水、异响、制冷效果差，
可申请免费返工；超过 7 天按维修流程处理。

## 与退换货的关系

已安装的大家电申请无理由退货时，需先拆除并恢复包装，拆机费用按服务标准收取。
