# 报修要准备哪些信息

报修建单时会采集下面这些信息。**不是每项都必须有，但缺项越多，二次上门的概率越高。**

## 一、身份与凭证

| 信息 | 为什么需要 | 没有怎么办 |
| --- | --- | --- |
| 订单号 | 定位购买记录与购买时间，判断是否在保修期 | 可用下单手机号或购买凭证替代 |
| 购买凭证 | 保修起算依据 | 电子发票、订单截图均可 |
| 联系人手机号 | 师傅上门前联系 | 必须提供 |

## 二、机器信息

| 信息 | 位置 / 说明 |
| --- | --- |
| 品类与型号 | 机身铭牌、说明书首页；订单详情里也有 SKU |
| 机身序列号（SN） | 铭牌或机身侧面条码，用于确认生产批次与保修 |
| 安装日期 | 安装工单里有；未安装的机器按签收日 |

型号报错会导致**备件带错**，是二次上门最主要的原因。型号不确定时，让客服按订单 SKU 反查。

## 三、故障现象（越具体越好）

- 出现时间与频率：偶发还是持续，每天几次；
- 具体表现：不制冷 / 不进水 / 不排水 / 异响 / 漏水 / 报错码；
- **故障码原文**（如 E1、E4），不要只说「报错了」；
- 是否伴随：异味、冒烟、结冰、机身发烫、跳闸；
- 已做过的排查：是否断电重启、是否清洗滤网、是否已按排查文档处理；
- 环境信息：水压、楼层、电压是否稳定（老小区尤其相关）。

## 四、上门条件

| 信息 | 说明 |
| --- | --- |
| 详细地址 | 门牌号、楼栋、是否有电梯 |
| 可上门时间窗 | 建议给两个备选，便于排班 |
| 门禁/物业要求 | 是否需要提前登记、是否限行时段 |
| 拆装需求 | 嵌入式安装、需拆柜体、需拆门，需提前说明 |

## 五、特殊情况要提前说

- 机器安装在吊顶、夹层、高空外机位（涉及高空作业与安全）；
- 商用场景或非家庭环境（保修范围可能不同，见《保修政策》）；
- 机器已被第三方拆修过（会影响保修判定）；
- 同一故障已维修过，需带上次工单号。

## 采集顺序建议

先确认**身份与订单**（能不能保）→ 再确认**型号与 SN**（带什么件）→ 再问**现象**（怎么修）→
最后约**时间与地址**（什么时候去）。顺序反了容易来回补问。
